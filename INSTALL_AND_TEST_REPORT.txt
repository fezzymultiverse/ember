EMBER 1.10.17 — PANEL-WIRED-2 PATCH

This is an updated source project, not an APK. The uploaded original ZIP has not been overwritten.

APPLY SAFELY
1. Export a backup using Ember's existing backup control before updating your own project.
2. Use this complete source project, or replace your project's entire www/ directory with the supplied www/ directory. Do not open the concept HTML as the app.
3. For the web app: npm ci, then npm run serve; open http://localhost:8080.
4. For Android: copy www into your existing Capacitor project, run npm run sync, and rebuild/install with the same app ID and signing key. This upload contains android_patch, not a complete Android Gradle project; no APK was compiled here.
5. Reload the app after updating. The service-worker cache and changed script URLs were refreshed. Do not uninstall or clear app data as an update step.
6. If rolling back, restore the original www/ directory. Retain an app backup independently.

WHAT IS CONNECTED
- The supplied concept's seven categories and 21 tool routes are imported into the real app, with its original embedded Ember logo.
- Open the concept panel with the Actions/star button beside Settings. The existing Settings gear still opens the real settings screen.
- Search filters individual tools; categories expand/collapse; Escape, focus containment, backdrop dismissal and app Back integration are connected.
- Real provider, notes, browser, music, downloads, project, timer, device, terminal, GitHub and settings controllers are used. Media selection arms the next message; it does not secretly generate media. Lyrics prefill an editable chat request rather than claiming to have created lyrics.
- Existing GitHub authentication and confirmation gates remain. Only its published-log decode changed: the old 3,500-character tail limit was removed while secret redaction remains.
- The actual Stop button is accessible again; a stalled reply was cancelled through app.js in the browser test.
- Body-wide keyless mounting on each DOM insertion was replaced by a plugin-target observer. Idle provider-key polling was reduced. Closed Command Centre layout no longer contributes offscreen document overflow.

FULL OUTPUT
- Removed 3,000-character terminal-line and 60,000-character event limits.
- Complete redacted output is archived in local IndexedDB. The live terminal renders at most 1,000 lines; Older/Newer/Latest page through the archive. Copy copies the full archive; Save full log downloads the complete redacted text.
- Complete output is not the same as unlimited DOM nodes. Paging prevents logs from continually increasing live DOM size.
- Reload persistence was tested after flushing. Abrupt OS termination, full device storage and browser data clearing are not guaranteed recovery scenarios.
- If persistent storage is unavailable, a visible warning says history is session-only. Export before closing.
- Clear removes the current tab session's log; Delete everything also purges the archive across sessions.
- Scrape-test output and text attachments are no longer silently clipped. Text uploads above 2 MB are explicitly refused instead of attaching only part of a file.
- This does not bypass provider token limits, GitHub content API limits, upstream omissions or Android permission restrictions. Existing repository context/read budgets remain unchanged.
