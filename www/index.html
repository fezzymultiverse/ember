Free Mode
Enable Free Mode (No Keys Needed)

Chats go through Pollinations.ai, a free third-party service, so your messages leave this phone. It is slower, rate-limited for anonymous use, and has no uptime promise. Keys stay on this phone. Free Mode is never used for background memory work. It is not a crisis line: if you are in danger, contact local emergency services or a crisis line now.

Permissions

Checking…

Notifications fire while the app is backgrounded and have a real reply box. Needs android_patch/ copied into your android/ project and built — see docs/ANDROID_PERMISSIONS.md. Music library reads your device's audio files; Prodigy playback control is not wired yet.

Voice
Read replies aloud automatically

Every reply also has a 🔊 button to read just that one. Voice input (🎤) uses the phone's speech service (Google, on most Android phones), which can send the audio to Google. It needs microphone permission. In the installed app it uses the native Android recogniser; in a browser it uses the browser's own.

Add-Ons
Music Control

When on, you can ask Ember about your music: what's playing, search Spotify, create playlists, and control playback. Requires the EmberMedia bridge (connect via your music player app).

Document Reading

When on, Ember can read, search and summarise documents in your vault. Requires the EmberDocs bridge (connect via Conduint Files or Bojack Secures). Document text is sent to whichever engine answers, including Free Mode, so leave this off for anything private.

Web Scraping
Enable Web Scraping & Saved Sites

Providers are tried in this order, skipping any without a key: Firecrawl, Browserless, ScraperAPI, ScraperBee, Sting, ZenRows, SerpApi (search snippets only), Octoparse (not supported yet). Page text is sent to whichever chat engine answers, including Free Mode. Keys stay on this phone and are not in backups.

Local checks are instant. Provider checks fetch example.com once per provider, so each uses a small amount of that provider's credit.
