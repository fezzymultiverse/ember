# Wiring map — 1.10.17 safe release candidate

## Scope and honest status

The immutable Phase-1 snapshot covers **371 pre-change working-tree files** (370 supplied ZIP members plus a generated npm lockfile), including **86 www JavaScript files** (vendor included) and **25 stylesheets**. It was generated after dependency setup but before application code changes and retained as WIRING_BASELINE.json. The uploaded tree differs from the approximate counts in the prompt; these are the observed counts.

FILE_RECEIPTS.json records exactly one final accounting state for every original member: WIRED, RETIRED or MERGED (none merged). WIRED here means an identified runtime/support/build/test/documentation/evidence link; it does **not** certify an all-green behavioral feature. RETIRED sources remain intact at the stated archive/history destination. All original documentation content is additionally retained before rewrite. No original path disappeared without a destination.

The overall release remains a candidate because inherited tests fail or time out and four legacy incoming events have no producer. Static analysis cannot prove arbitrary dynamic property resolution, every possible tool call or live Android behavior. The raw AST and runtime evidence are included; unknowns are not replaced by fictional endpoints or listeners.
