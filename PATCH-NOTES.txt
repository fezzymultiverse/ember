EMBER / LOCAL PDF + BOOT SCREEN PATCH

Scope: only 10 existing files changed (five root files and their five www copies).
1272 original files are byte-for-byte unchanged; no original files removed.
Root/www index files were patched separately to preserve their pre-existing differences.
Existing package version and dependencies were deliberately not changed.

BOOT
- Ember-branded dark startup screen using the original bundled flame asset.
- Mobile and desktop layout, safe-area spacing, reduced-motion support.
- Startup status, immediate Continue button, load completion and 4.5-second escape timeout.
- No generated artwork, external fonts, remote image requests or new dependencies.
- This is the app's web startup screen. Android native/OS splash resources are unchanged.

PDF
- Direct local PDF generation with bundled pdfmake and embedded Roboto fonts.
- No PDF API, provider key, cloud upload or DOCX intermediate.
- Removed the cloud-PDF provider loop and artifact cloud fallback.
- Legacy cloud method names remain inert compatibility shims; they cannot upload content.
- Legacy cloud settings are forced to local when read; no new remote integrations added.
- Readable A4 margins and typography, running header/footer, page numbering.
- Configurable Letter/landscape and optional linked contents page through pdf options.
- Repeating table headers, striped rows, oversized-cell continuation rows, nested lists,
  checklist markers, quotations, code, clickable links and heading widow protection.
- Load/render timeouts, retry after failed bundle load, input limits, PDF header/EOF checks.
- Service-worker cache version refreshed; cold offline reload tested.
- Word export is preserved, not used to create PDFs. Unrelated chat, music, web and other
  API/provider integrations are deliberately unchanged to respect 'touch nothing else'.
